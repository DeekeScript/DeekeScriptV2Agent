# 运行与同步

生成代码时必须遵守下列运行边界。用户明确问 VSCode 插件怎么点时，再用文末「插件命令」回答。

自动调试、写文件到手机：优先 [`device.md`](./device.md)（`POST /ai/project/write` + `run` / `run-file`）。

## 运行边界（生成时必守）

| 文件 | 怎么跑 |
|------|--------|
| `tasks/*.js` | `Engines.executeScript('tasks/xxx.js')`，或编辑器「仅当前文件执行」 |
| `page.js` | 只在打开对应页面时由引擎加载；**禁止**当任务脚本执行 |
| `component.js` | 随页面/弹层里的组件实例加载 |

- 没有入口文件 / 同步失败：见 [`constraints.md`](./constraints.md) MUST 1。
- 改 `page.json` / `page.js` / 组件后须同步到手机；当前页打开时会热更新，否则手机端点刷新。
- 页面按钮启动任务：`Engines.executeScript('tasks/xxx.js')`（见 [`events.md`](../01-ui/events.md)）。
- 死循环或不想再跑：停掉手机上正在执行的脚本（插件「停止所有脚本」，或 `/ai` 的 stop）。

## 手机侧开关

执行 / 调试前手机需开启：无障碍、悬浮窗；自动调试还要 **节点查看**（8080）。用户问插件连接时再提「开发模式」。

## 插件命令（仅当用户问 VSCode 操作）

插件：市场安装 **DeekeScript Pro**。手机与电脑同一局域网。

| 命令 | 作用 |
|------|------|
| 连接手机 / 关闭连接 | 填手机局域网 IP |
| 打开控制台 | 看 `console.log`、同步日志、报错 |
| 项目同步 | 同步整个工程 |
| 文件同步 | 只同步当前打开的文件 |
| 仅当前文件执行 | 执行当前 `tasks/*.js` |
| 停止所有脚本 | 停掉手机上正在跑的脚本 |

同步后手机点 **刷新**；有界面的工程进入 `homePage`。

工程结构见 [目录](./project-layout.md)，语法见 [运行时](./runtime.md)。
