# backend

企业后台：管激活码、代理商、AI 角色、App 更新、广告图、数据大屏。给运营用，不是脚本 API。

## 上下文

| 角色 | 说明 |
|------|------|
| 系统管理员 | 登录后台 |
| 代理商 | 用点数创建卡密 |

脚本侧对接的是 [`activation.md`](./activation.md) 那些 HTTP 接口，不是后台页面本身。

## 功能（官方列表）

- 系统管理员 / 代理商登录
- 创建代理商（按点数控制可制卡数量）
- 代理商创建卡密：1 天、3 天、7 天、30 天、3 月、6 月、1 年、2 年
- AI 角色与密钥配置
- APP 后台更新
- 开屏广告图、支付广告图
- 数据大屏

## 生成时注意

- 不要在 `deekeScript-v2.json` 里编造后台地址字段。域名用 `host`。
- 卡密期限与 `payList.day` / `money` 对应关系见 [`activation.md`](./activation.md) 的 `config` 接口。
- 没有公开的「后台 SDK」对象，不要生成 `Backend.xxx()`。
